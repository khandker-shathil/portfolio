# Khandker Shathil — Portfolio

Next.js App Router, React, TypeScript, Tailwind CSS v4, and a shadcn/ui-style Button built with Radix Slot and class-variance-authority. Static export supports hosting without a server.

## Develop

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Deploy the generated `out/` directory to a static host, or import this Next.js project into Vercel.

## Personalize

Edit `lib/content.ts` to add public email, phone, GitHub, LinkedIn, resume, portrait, and project details. Put assets in `public/`, then use paths such as `/portrait.jpg` and `/resume.pdf`. The resume becomes a download link automatically. Project links, technology stacks, images, challenges, and improvements are shared with their individual detail pages.

The site intentionally labels missing content. Two project slots await the owner's real projects; the third is planned. To meet the assignment in full, add three completed projects, a professional photo, contact details, social links, and a public live deployment. Professional experience is omitted because none was provided. Education is based on the owner's stated CSE graduation in 2026.
